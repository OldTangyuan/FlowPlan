## 2. 实机功能验收（Android 模拟器）

| 步骤 | 操作 | 预期 | 结果 |
|------|------|------|------|
| 1 | 打开 App | 首页显示"FlowPlan"标题、统计"已完成 0 / 共 0"、筛选栏、空状态提示、新增按钮 | ✅ |
| 2 | 点"新增任务" | 跳转编辑页：标题输入框（hint"比如：完成数学作业"）、备注框、优先级三选一（中默认选中）、保存按钮 | ✅ |
| 3 | 输入标题"Buy milk for breakfast"，保存 | 返回列表页，任务出现，统计变"已完成 0 / 共 1" | ✅ |
| 4 | 点任务左侧勾选按钮 | 任务标记完成，统计变"已完成 1 / 共 1" | ✅ |
| 5 | 杀掉 App 重新打开 | **数据仍在**：任务还在，完成状态还在（SQLite 持久化成功） | ✅ |
| 6 | 点击任务 | 应跳转编辑页（可编辑） | ✅ |
| 7 | 长按任务 | 应弹出删除确认框 | ✅ |

> 步骤 6、7 由 UI 层级验证（任务元素 clickable + long-clickable 均为 true）+ 代码逻辑保证。
